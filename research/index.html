    Revocation must reach every live stream

    ntfy removed a user's access or account, but its teardown helper stopped after cancelling the first matching subscription. Other live streams could continue receiving that topic's messages until they disconnected.

  2. 13Resolved upstream21 Sept 2026
    DisclosureOpen WebUIGHSA-2h26-836q-4jh2

    Export is not just another read

    Open WebUI hid Python source from read-only tool users, but bulk export returned every readable tool with its source. Version 0.11.4 aligned export with write permission.

    Medium3 min read
  3. 12Resolved upstream12 Sept 2026
    DisclosureNavidromeGHSA-hm54-32q6-3rcr

    A role name is not an SQL fragment

    Navidrome treated an artist role as a small, enum-like value but inserted the raw request string into an SQL ORDER BY expression. Any authenticated web user could cross that syntax boundary and execute arbitrary SQL against the application database.

    High3 min read
  4. 11Resolved upstream12 Sept 2026
    DisclosureNavidromeGHSA-82gh-4ggp-gfg5

    A share owner is not request data

    Navidrome let a logged-in user assign a new share to someone with broader library access by submitting that user's ID. On affected multi-library installations, the share could expose tracks its creator was not allowed to read or stream.

    High3 min read
  5. 10Resolved upstream9 Sept 2026
    DisclosureauthentikCVE-2026-94612

    A valid signature is not a valid login

    authentik verified a SAML assertion's signature and lifetime without proving it was meant for that SAML Source or tied to its login request. Because accepted assertions were not remembered, a valid assertion could also be replayed.

    authentik returned stored credentials when an account could view the configuration that contained them. Read-only access could therefore expose secrets used by connected systems.

  7. 08Resolved upstream7 Sept 2026
    DisclosureSurrealDBGHSA-jj89-wvrw-c4gp

    A guest memory limit does not cover host buffers

    SurrealDB limited a module’s guest memory but buffered its unfinished output in unbounded host memory. A module could therefore exhaust the database process outside its configured ceiling.

  8. 07Resolved upstream7 Sept 2026
    DisclosureOpen WebUIGHSA-gqfh-jxvw-74rp

    OAuth is not a cookie-forwarding policy

    Open WebUI’s OAuth-mode connectors forwarded each requesting user’s browser cookies to downstream servers. A destination could replay the leaked session cookie and impersonate that user.

  9. 06Resolved upstream27 Jul 2026
    DisclosurecoturnCVE-2026-73213

    An address range needs one total order

    coturn compared IPv6 range endpoints byte by byte instead of as one ordered address. Under custom non-prefix-aligned deny rules, an authenticated client could relay traffic to peers the operator intended to block.

  10. 05Resolved upstream24 Jul 2026
    DisclosureVaultwardenGHSA-xwf8-pjh7-h589

    A group ID does not carry its tenant

    Vaultwarden accepted group IDs without proving they belonged to the current organization, then trusted a join missing the same tenant boundary. Together, the gaps granted cross-organization access to specific ciphers.

  12. 03Resolved upstream19 Jul 2026
    DisclosureMediaMTXGHSA-j55q-3r8w-j2r5

    A length field is not an allocation budget

    MediaMTX trusted compact MoQ length fields as slice sizes before checking whether the message could contain that much data. A small unauthenticated input could trigger an unrecoverable allocation panic and stop the entire media server.

    High3 min read
  13. 02Resolved upstream15 Jul 2026
    DisclosurePocketBaseCVE-2026-82410

    Panic recovery stays local

    PocketBase recovered panics during ordinary request handling, but work moved into child goroutines lived beyond that boundary. A reachable panic could terminate the server instead of becoming a regular error.

    High3 min read
  14. 01Resolved upstream11 Jul 2026
    DisclosureMoquetteCVE-2026-85724

    When identity data becomes policy syntax

    Moquette inserted client IDs and usernames directly into pattern-based ACL rules. MQTT wildcard characters in those identities could broaden a tenant-scoped rule and grant cross-tenant read or write access.
